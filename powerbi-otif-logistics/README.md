# Power BI OTIF Logistics Dashboard

Portfolio-ready Power BI case centered on OTIF performance, order flow, delay exposure, and logistics monitoring.

## Overview

This case is built around OTIF style logistics visibility. It frames delivery performance through order timeliness, delay risk, and operational bottlenecks in a way that feels concrete for supply chain, planning, and service-oriented roles.

The public portfolio version focuses on the use case, KPI structure, and operational story. That makes it stronger for GitHub and static web presentation than uploading a dashboard file without context.

## What It Demonstrates

- logistics KPI design in Power BI
- OTIF performance framing for business users
- operational storytelling using delay and order-flow indicators
- a portfolio angle that feels more operational than generic reporting

## Portfolio Notes

- The original working files reviewed locally include two OTIF dashboard variants.
- For public presentation, this case is treated as a single polished logistics story rather than separate draft versions.
- This is one of the strongest cases in the Power BI folder because it communicates analytical depth and operational context at the same time.
