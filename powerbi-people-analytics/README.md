# Power BI People Analytics

Portfolio Power BI case focused on workforce monitoring, attendance-related signals, and people analytics storytelling.

## Overview

This case translates HR and workforce indicators into a compact Power BI narrative. Compared with the logistics and sales cases, it is less universal for every hiring manager, but still valuable as a third project because it broadens the portfolio and shows versatility.

## What It Demonstrates

- Power BI reporting for workforce and HR-oriented metrics
- people analytics framing through attendance, contracts, onboarding, and work patterns
- use of visuals and iconography to make an internal dashboard more approachable
- breadth across domains beyond industrial and commercial reporting

## Portfolio Notes

- The original file name was a working-title version. The public portfolio uses the cleaner project name `Power BI People Analytics`.
- This case is best presented as a complementary example rather than the first project a recruiter sees.
- It helps the portfolio feel wider without distracting from the stronger flagship Power BI stories.
