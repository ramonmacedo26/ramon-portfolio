# Power BI Sales vs Target

Portfolio-ready Power BI case focused on commercial performance, target attainment, and sales visibility.

## Overview

This case presents a recruiter-friendly sales dashboard built in Power BI to compare realized revenue against target, highlight attainment gaps, and support faster follow-up on performance by period and sales slice.

It is positioned as a business analytics case rather than a raw dashboard file drop. The goal is to show KPI framing, stakeholder communication, and clean presentation.

## What It Demonstrates

- target vs actual performance tracking
- business-facing KPI design in Power BI
- visual storytelling for commercial monitoring
- portfolio-safe framing for GitHub and static web presentation

## Portfolio Notes

- The original `.pbix` file was reviewed locally from the Power BI working folder.
- The public portfolio emphasizes the case narrative and business value rather than exposing raw source data.
- This case works well as a featured Power BI example because the problem is immediately clear to recruiters and hiring managers.
