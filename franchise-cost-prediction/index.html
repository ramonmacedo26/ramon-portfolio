Why this works in a portfolio

This demo shows the full path from data to interface: ingesting a structured sample, calculating a regression model, exposing inputs, and presenting a clean business-oriented output.

Why HTML helps here

A static frontend is easier to publish on GitHub Pages, easier to embed into a portfolio site, and removes the operational overhead of a Python runtime for a simple showcase project.
